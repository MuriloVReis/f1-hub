## 🏁 Sobre o projeto

O **F1 Hub** é um projeto acadêmico desenvolvido com o objetivo de unir uma interface web moderna a uma **API desenvolvida em Python**.

A proposta é criar uma experiência inspirada em plataformas esportivas, permitindo que o usuário consulte e visualize informações relacionadas à Fórmula 1 de forma simples, rápida e organizada.

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web, com foco na integração entre **Front-end e Back-end**.

## 🖥️ Interface

O F1 Hub possui uma interface inspirada na identidade visual da Fórmula 1, utilizando principalmente **preto, vermelho e tons escuros**.

A página inicial apresenta uma área principal com:

- Identidade visual do F1 Hub;
- Navegação entre as principais áreas da plataforma;
- Hero section com destaque para a Fórmula 1;
- Campo de pesquisa;
- Acesso às informações disponíveis no sistema.
